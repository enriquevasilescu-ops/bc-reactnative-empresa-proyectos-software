# Proyecto Semana 03 - API REST

## Empresa de Proyectos de Software

### Descripción

Este proyecto corresponde a la actividad de la Semana 03, donde se desarrolló una API REST utilizando TypeScript y Express.

La API está enfocada en una empresa de proyectos de software y permite realizar operaciones CRUD sobre diferentes proyectos de software.

Para organizar el proyecto se utilizó una arquitectura en capas:

- Routes
- Controllers
- Services
- Repositories

El objetivo es separar las responsabilidades de cada parte de la aplicación y tener un código más organizado y fácil de mantener.
